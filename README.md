## About This Study Repository

This repository serves as a personal learning lab and technical notebook for building foundational web development and version control habits. Rather than a finished production product, each file and reference document focuses on isolating specific concepts, testing behavior in the browser or terminal, and documenting team collaboration steps.

### What Is Being Studied Here

- **CSS Styling & Positioning (`style_2.css`):** Experimenting with page backgrounds (`bisque`), header styling (`position: relative`), centered navigation (`display: flex; justify-content: center;`), inline-block elements (`.posicao`), floating action badges (`.whats` using `position: fixed`), and sticky headings (`h2` using `position: sticky; top: 0px`).
- **JavaScript Logic & Conditionals (`app.js`):** Practicing logical operators (`&&` AND, `||` OR, `!` NOT) through simple `if/else` statements, compound conditions, multi-condition expressions, and negated conditions output to the console.
- **Git & GitHub Team Workflow (`Git e GitHub - Trabalho em Equipe com Branches.pdf`):** Studying branch-based collaboration (such as separate `estilo` and `javascript` branches), repository cloning, Git user configuration, staging/committing changes, pushing branches, local merges vs. Pull Requests, and resolving merge conflicts.
